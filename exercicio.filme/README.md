# 🎸 Viva – A Vida é uma Festa

## 📖 Sobre o projeto

Este projeto é uma página web sobre o filme **Viva – A Vida é uma Festa (Coco)**.

A página foi desenvolvida utilizando **somente HTML**, com o objetivo de praticar os principais conceitos de criação e organização de páginas web.

O projeto foi desenvolvido no **Visual Studio Code (VS Code)** e posteriormente disponibilizado no **GitHub**.

## 🎬 Sobre o filme

**Viva – A Vida é uma Festa** é uma animação lançada em 2017 que conta a história de **Miguel Rivera**, um garoto apaixonado por música.

Apesar de sua família não permitir que ele siga seu sonho de ser músico, Miguel continua buscando uma forma de realizar seu desejo.

Durante o **Dia dos Mortos**, ele acaba entrando no Mundo dos Mortos e começa uma aventura para descobrir mais sobre sua família e seu passado.

## 🖥️ Como abrir o projeto no VS Code

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no **Visual Studio Code**.
3. Localize o arquivo `index.html`.
4. Clique com o botão direito no arquivo.
5. Selecione **"Open with Live Server"**, caso tenha a extensão instalada.
6. A página será aberta no navegador.

Também é possível abrir o arquivo `index.html` diretamente no navegador.
